# Asset attribution

Preserved logos come from Devicon, Simple Icons, CNCF artwork, and official project repositories. Original source records are included in docs/DEVOPS-ASSET-SOURCES.json and docs/KUBERNETES-ASSET-SOURCES.json. Marks belong to their owners and do not imply endorsement.

Covers, galleries, badges, and diagrams use original repository-native vector layouts. Resource cards are conceptual labels, not official resource logos. Docker components share an explicitly identified Docker ecosystem mark. The official VERIQTA symbol was unavailable, so assets use plain VERIQTA text.
